# Wisnu Agus Wicaksono — Personal Portfolio

Website portofolio pribadi yang menampilkan profil, keahlian teknis, proyek, sertifikasi, serta pengalaman organisasi dan kerja. Website ini dikembangkan sebagai media untuk memperkenalkan latar belakang, kemampuan, dan hasil pengembangan proyek di bidang Web Development dan Data Analysis.

## Features

- **Personal Profile** — Informasi diri, pendidikan, pengalaman kerja, dan pengalaman organisasi.
- **Tech Stack Showcase** — Tampilan teknologi dan tools yang pernah digunakan.
- **Project Portfolio** — Dokumentasi proyek Web Development dan Data Analysis.
- **Certifications & Training** — Informasi pelatihan dan sertifikasi yang telah diikuti.
- **Organization Gallery** — Dokumentasi visual kegiatan organisasi.
- **CV Download** — Akses untuk mengunduh CV dalam format PDF.
- **Bilingual Interface** — Pilihan bahasa Indonesia dan Inggris.
- **Responsive Design** — Tampilan yang menyesuaikan berbagai ukuran layar.
- **Interactive UI** — Animasi, transisi, modal informasi, dan galeri dokumentasi interaktif.

## Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Figma
- WebP — Optimasi aset gambar

## Getting Started

1. Clone repository ini:

   ```bash
   git clone <repository-url>
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd Website-Portofolio
   ```

3. Buka `index.html` di browser untuk melihat website.
